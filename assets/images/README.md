# Fitin 사진 폴더 (온보딩용)

여기에 Fitin 사진을 넣으면 페이지에서 `assets/images/파일이름` 으로 불러옵니다.

## 폴더 구분
| 폴더 | 넣을 사진 | 쓰이는 곳 |
| --- | --- | --- |
| `hero/` | 가로로 긴 대표 사진 (센터 전경, 트레이닝 장면) | 메인 첫 화면 |
| `trainer/` | 트레이너 프로필, 코칭 장면 | 트레이너 소개 |
| `facility/` | 운동 공간, 장비 | 시설 소개 |
| `program/` | PT/루틴 진행 장면 | 온보딩 3단계, 루틴 레벨 |

## 파일 규칙 (전문적으로 보이기 위한 최소 기준)
- 이름: 영어 소문자 + 하이픈, 공백·한글 금지 → `hero-main.jpg`, `trainer-coaching-01.jpg`
- 형식: `.jpg` 또는 `.webp` (투명 배경 필요할 때만 `.png`)
- 크기: 가로 최대 2000px, 파일당 500KB 이하 권장 (너무 크면 휴대폰에서 느림)
- 회원 얼굴이 나오는 사진은 본인 동의를 받은 것만 사용
